# Guia de Contribuição — Linux AI Assistant

Agradecemos o interesse em contribuir com o **Linux AI Assistant**!

Nosso objetivo é construir uma ferramenta confiável, acessível e educativa para a comunidade Linux.

---

## 📌 Diretrizes Gerais

1. **Didática em Primeiro Lugar:** Toda mensagem ou resposta formatada pelo assistente deve priorizar clareza, evitando termos técnicos desnecessários sem a devida explicação.
2. **Segurança Inegociável:** Qualquer funcionalidade que interaja com o sistema operacional deve respeitar o princípio do menor privilégio. Nunca execute comandos sem validação prévia.
3. **Decisões Documentadas:** Mudanças significativas na arquitetura devem ser propostas e registradas no [DECISIONS.md](DECISIONS.md).

---

## 🛠️ Como Contribuir

1. Faça um Fork do repositório no GitHub.
2. Crie uma branch com a sua feature ou correção:
   ```bash
   git checkout -b feature/minha-melhoria
   ```
3. Realize seus commits de forma clara e descritiva.
4. Envie sua branch para o seu fork:
   ```bash
   git push origin feature/minha-melhoria
   ```
5. Abra um **Pull Request** detalhando as alterações realizadas e os testes executados.
